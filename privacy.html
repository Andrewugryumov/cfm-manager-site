Privacy Policy

Effective date: October 13, 2026

CFM — Cloud File Manager (“CFM”, “the app”, “we”) is an Android file manager application that allows users to work with local files and cloud storage accounts.

Information the app accesses

When a user chooses to connect Google Drive, CFM requests permission from the user through Google OAuth. Depending on the permissions granted, the app may access Google Drive file and folder metadata, file names, file content required for downloading or opening files, and file content selected for uploading.

How Google user data is used

Google Drive data is used only to provide file manager features requested by the user, including viewing folders, downloading files, uploading files, renaming files, deleting files, and opening files.

Data storage

CFM does not operate a separate server for storing Google Drive files. Files downloaded by the user may be stored locally on the user’s device. Authorization data required for sign-in may be stored locally on the user’s device to keep the user signed in.

Data sharing

CFM does not sell Google user data. CFM does not share Google user data with third parties. CFM does not use Google user data for advertising or user profiling.

Google API Services User Data Policy

CFM’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

User control and revocation

Users can revoke the app’s access to their Google Account at any time from their Google Account security settings. Users can also remove downloaded files from their device using the app or Android system file tools.
